# Tool Usage — Terminal Commands

Quick reference for the NAND2Tetris software suite. Run these from the `tools/` directory (or with `tools/` on your `PATH`).

## Hardware Simulator

| Mode | Command |
|------|---------|
| Interactive | `HardwareSimulator` |
| Batch | `HardwareSimulator <file>.tst` |
| Help | `HardwareSimulator -h` |

## CPU Emulator

| Mode | Command |

| Batch | `CPUEmulator <file>.tst` |
| Help | `CPUEmulator -h` |
